# lspml

A language server for the Sitepark Markup Language (spml).

## Agent skills

### Issue tracker

Issues live as GitHub issues in `Schleuse/lspml`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels, used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
